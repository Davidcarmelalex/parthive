## What is PartHive?

PartHive is a premium automotive sourcing ecosystem that bridges UAE vehicle owners with certified workshops through AI-driven part diagnostics and seamless doorstep fulfillment. Covering Dubai, Abu Dhabi, Sharjah, Ajman, and Ras Al Khaimah.

## Tech Stack

- **Frontend:** Next.js 16 · TypeScript · Tailwind CSS
- **AI:** TensorFlow.js · Computer vision for part recognition
- **Backend:** Node.js · Express · PostgreSQL
- **Maps:** Google Maps API · Workshop location services
- **Logistics:** Custom delivery tracking

## Quick Start

```bash
git clone https://github.com/Davidcarmelalex/parthive.git
cd parthive
npm install
cp .env.example .env.local
npm run dev        # http://localhost:3000
```
